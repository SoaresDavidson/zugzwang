# Zugzwang

Revisão de partidas de xadrez no navegador, com Stockfish WASM. Veja `SPEC.md` para o escopo e `docs/superpowers/plans/` para o plano de implementação.

## Desenvolvimento

```bash
npm install      # também copia o Stockfish para public/stockfish
npm run dev
npm test
```
